# Ganymede-Lab-Assistant

An interactive lab assistant made for makers. Part of Project: Ganymede, coded in Python.

## Planned Features

- Dashboard GUI built using NiceGUI
- Components/Inventory Tracker
  - Keep track of resources and inventory
- Project Hub
  - View active projects, link inventory parts to projects for organization
- Ollama Intergration
  - Chat pannel for local Ollama models
- Hackatime Intergration
  - Can link to Project Hub
- Physical Voice Assistant
  - Similar to Alexa or Google Assistant
